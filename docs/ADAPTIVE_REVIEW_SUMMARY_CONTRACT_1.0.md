# Adaptive Review Summary Contract 1.0

CTOD finalized review summaries are adaptive portrait reports, not fixed two-page documents.

Requirements:
- Generate as many Letter portrait pages as needed.
- Never clip, overlap, or hide review content.
- Key Strengths and Development Areas use full-width stacked rows: Question -> Rating -> Reason -> Manager note.
- Goals and coaching may continue onto additional pages.
- Section headings repeat with '(continued)' when a section spans pages.
- Acknowledgment and employee/manager signature lines remain at the end of the report and are never clipped.
- PDF download and print must export all generated pages, 1 portrait page per sheet.
- Same behavior applies to every employee, manager, location, tenant, and future customer.
